# Database schema

The schema is documented here per rule 1.6: every table and column carries a
description. It is kept in sync with `src/lib/db/schema.ts` and the generated
migrations in `/drizzle`.

## Conventions

- UTF-8 encoding on both databases so Urdu content stores correctly from day one.
- Timestamps are `timestamptz` (UTC).
- Migrations are versioned SQL, generated by Drizzle Kit and committed; the
  schema is never hand-edited against a live database.

## Databases

| Database    | Purpose                                   |
| ----------- | ----------------------------------------- |
| `issb_dev`  | Local development (`APP_ENV=development`) |
| `issb_prod` | Local production (`APP_ENV=production`)   |

Owner/role: `issb_app` (least privilege — `NOSUPERUSER NOCREATEROLE NOCREATEDB`).

## Tables

### `app_metadata`

A typed key/value store for system-level facts. Introduced in Phase 0; the
health readiness probe reads it and the seed script writes to it.

| Column        | Type          | Nullable | Description                                         |
| ------------- | ------------- | -------- | --------------------------------------------------- |
| `key`         | `text` (PK)   | no       | Stable key, e.g. `schema.baseline`, `seed.status`.  |
| `value`       | `jsonb`       | no       | Arbitrary JSON payload for the key.                 |
| `description` | `text`        | yes      | Human-readable note describing what the row is for. |
| `updated_at`  | `timestamptz` | no       | Last write time (UTC), defaults to `now()`.         |

Seeded rows:

- `schema.baseline` → `{ "phase": 0, "note": "Foundation baseline" }`
- `seed.status` → `{ "seeded": true }`
